## 1. What the project is

Sway re-runs an AI shopping agent's decision with each web page it read removed. If the page that decided the purchase is honest, the payment is captured and the publisher is paid through PayPal Payouts. If it's dishonest (hidden text, instructions aimed at AI agents, claims that contradict the real Channel3 catalog), the PayPal authorization is voided.

Two parts:
- **Python engine (`sway/`):** the ablation check, the simulated shopper agent, the benchmark (`bench.py`) and the API on port 8787.
- **Next.js site (`site/`):** pages, API routes, the PayPal integration, and an order ledger stored in `data/orders.json`.

## 4. Prompt 4: what was built

### Operator audit ledger (`/ops`, "Audit ledger" view)
- AG Grid Community, **infinite row model**. This is the server-paged equivalent, because the "server-side row model" you named is AG Grid Enterprise only.
- Columns: timestamp, agent ID, human ID, product (Channel3 id and title), deciding page URL, honesty verdict (pass or fail plus reason tag), PayPal order (link to sandbox when it exists), outcome, payout recipient, amount, currency, and actions.
- Floating text filters, sorting and paging all happen on the server.
- Row actions: **Approve** (capture), **Void**, **Refund**. Each asks for confirmation in an accessible dialog. A refused action is announced in a live region.
- Keyboard: arrow keys, Home and End move between cells. On a row, `A`, `V` and `R` trigger the actions. Enter on the Actions cell moves into its buttons.
- Status cells show an icon plus text. Colours come from the site's theme tokens and have a dark variant.
- Deciding page URLs are shown as plain text, not links, because they may be attack pages.

### New and changed code (all under `site/`)
- `app/ops/ledger-grid.tsx`: the grid. `app/ops/ops.tsx`: now has the "Audit ledger" toggle and a "Payout schedule" link when the flag is on.

- `app/api/shop/refund/route.ts` and `refundCapture` in `lib/server/paypal.ts` (with a mock): a refund route did not exist, so I added one.
